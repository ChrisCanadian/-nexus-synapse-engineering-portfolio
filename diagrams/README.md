# Diagrams and Visual Sources

The repository uses public-safe visuals as orientation aids. The claim-bearing source remains the version-controlled documentation and evidence files.

The largest visual assets are mirrored through the Nexus Synapse Research Library / Google Drive rather than duplicated as binary source blobs in this repository. The visual gallery embeds those public images directly.
